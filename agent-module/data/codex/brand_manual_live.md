> That purpose has four names: **Freedom, Justice, Prosperity, and Frontier**.

## 1.3 PAA Gap — 한 단계 향상

PAA Gap은 고객이 제품을 매개로 **자신의 정체성과 수행 능력을 현재보다 한 단계 높은 수준으로 인식하도록 만드는 핵심 격차**다.

PAA Gap은 **Aspirational Gap**과 **Functional Gap**으로 구성된다.

### 1) Aspirational Gap — 열망의 차이

고객이 현재의 자신보다 한 단계 상위의 **인물상**을 동경하도록 이끄는 방식이다.

제품을 착용했을 때 어떤 인물로 각인되고 싶은지를 정의하며, 이 상위 인물상이 라인의 비주얼·스타일링·카피 톤앤매너를 결정한다.

예를 들어 일반 아웃도어 소비자를 단순 하이커가 아닌 **목적을 갖고 적대적 지형을 개척하는 원정대원**으로 포지셔닝하는 것이 Aspirational Gap이다.

### 2) Functional Gap — 성능의 차이

고객의 일반적인 사용 환경보다 **더 높은 수준의 조건**에서 제품의 기능을 증명하는 방식이다.

내구성, 기동성, 수납성, 접근성, 방호력 등의 기능을 일상 수준 이상으로 극단화된 환경에서 시각화함으로써 제품의 성능 격차를 명확히 입증한다.

예를 들어 일반 러닝 셔츠의 기능을 단순 피트니스가 아닌, 장애물·과부하·오프 로드가 결합된 고강도 훈련 환경에서 증명해 내는 방식이다.

# SECTION 02 — 제품 기획 방향

## 2.1 CQR 3-Layer System

CQR의 모든 제품 및 비주얼 기획은 **Character · Loadout · Scene**의 3개 레이어 결합으로 완성된다.
Scene은 인물이 위치하는 환경을, Loadout은 수행 임무와 전문성을, Character는 정체성을 전달하는 중심이 된다.
세 레이어를 매끄럽게 조합하여 누가(Character), 무엇을 위해 어떤 장비를 갖추고(Loadout), 어디서 수행하는지(Scene)를 일관된 기획으로 연결한다.

| **Layer** | **정의** | **이미지 및 기획에서의 역할** |
| :--- | :--- | :--- |
| **Character** | 라인이 상징하는 인물상을 구체화한 페르소나 | 비주얼의 중심 — **누구인가** |
| **Loadout** | 특정 임무 수행에 필요한 장비·정보·권한의 체계 | 역할 및 임무 설명 — **무엇을 갖췄는가** |
| **Scene** | Character와 Loadout이 놓이는 환경 및 공간 | 세계관 및 무드 형성 — **어디에 있는가** |

## 2.2 Loadout — 로드아웃

로드아웃은 Character가 **특정 임무를 수행하기 위해 갖추는 장비·정보·도구의 총체적 구성**이다.

단순 착장 코디를 넘어 인물이 어떤 상황에서 무엇을 활용해 임무를 수행하는지 입체화한다. 동일한 Character라도 임무 국면에 따라 서로 다른 로드아웃을 운용할 수 있다.

로드아웃은 특정 라인에 귀속되지 않는 독립 모듈로서 관리되어, 여러 Character 간 교차 공유가 가능하다.
예를 들어 COVERT와 LIBERATOR MODERN은 서로 다른 Character지만, 지휘·결심 임무 시 동일하게 **LO-CMD** 로드아웃을 공유한다.

### 로드아웃의 상품 구성 3단계

| **단계** | **정의** | **기획에서의 역할** |
| :--- | :--- | :--- |
| **① 트리거 아이템 (Trigger Item)** | 해당 인물상과 라인업으로의 진입을 이끄는 핵심 CQR 첫 제품 | 핵심 기획 상품 및 셀링 포인트(USP) 정의 |
| **② 활성화 아이템 (Activation Item)** | 트리거 아이템과 조합되어 캐릭터를 완벽히 깨우는 서브 CQR 제품 | 크로스 셀링 및 연계 컬렉션 구성 기준 |
| **③ 외부 장비 (Context Equipment)** | CQR 제품은 아니지만 인물과 임무를 완전체로 만드는 외부 소품/장비 | 제품 디테일 설계 근거 및 촬영/렌더링 소품 가이드 |

### 제품 및 비주얼 기획 활용

* **제품 기획:** 트리거 및 활성화 아이템은 컬렉션 라인업 구성의 기준이 된다. 팬츠(트리거)를 기획할 때 이에 대응하는 셔츠·벨트(활성화)를 함께 세팅한다. 외부 장비는 디테일의 근거가 되어, GPS·무전기·툴 파우치 등의 크기 및 운용 방식에 맞춰 포켓 규격, 루프 위치, 마찰 보강 부위 등을 설계한다.
* **비주얼 기획:** 착장 메인 의상을 결정하며, 외부 장비 소품을 화면 내 적재적소에 세팅함으로써 단순 모델이 아닌 '현장의 오퍼레이터'라는 PAA(목적)를 시각적으로 증명한다.

### 라인별 Full Loadout 예시

| **라인** | **트리거 아이템** | **활성화 아이템** | **외부 장비** |

| **COVERT** | 슬림 카고 팬츠 | 무지 셔츠 · 로우프로파일 캡 | 컨실드 파우치 · 스마트워치 · 미니멀 배낭 |

## 2.3 Loadout 공간 배치 — Character와 Scene의 분리

로드아웃 내 장비는 **Character가 직접 착용/소지하는 모듈**과 **Scene 공간에 세팅되는 환경 모듈**로 엄격히 분리한다.

이 분리 원칙을 통해 동일 Character를 다양한 Scene에 유연하게 크로스오버 배치할 수 있다.

| **구분** | **포함 요소** | **설계 주체** |
| :--- | :--- | :--- |
| **Character** | 인물이 직접 착용·소지하는 의류, 가방, 휴대 단말기, 무전기, 배지, 소형 장비 | CQR 제품 기획 및 의상 디자인 영역 |
| **Scene** | 건축, 공간, 차량, 가구, 대형 디스플레이, 설치형 대형 장비 등 환경 요소 | 비주얼 커뮤니케이션 및 공간 연출 영역 |

예를 들어 통신 로드아웃(**LO-SIG**) 적용 시, 휴대 단말기는 Character 모듈에 파지시키고 대형 SATCOM 안테나는 Scene 배경 환경에 세팅하여 기어의 물리적 현실성을 확보한다.

## 2.4 Loadout Catalog — 로드아웃 카탈로그

로드아웃은 **특정 라인의 소유물이 아닌 임무의 성격을 기준으로 정의한다**.

'이동'이라는 임무는 EXPEDITION이나 COVERT 모두 동일한 **LO-MOV**를 공유해 사용한다.
네임스페이스는 `LO-` + 임무 약어로 단일 레지스트리에서 전역 ID로 통합 관리된다.

### 관리 원칙

* **단일 정의:** 로드아웃 정의는 레지스트리 한 곳에만 존재하여 중복을 차단한다.
* **전역 참조:** 라인명에 종속되지 않아 어느 라인에서든 자유롭게 교차 참조가 가능하다.
* **예외 관리:** 전속성이 필요한 특정 로드아웃(예: LO-CR)은 정의 시 명시적 예외 규칙을 부여한다.

| **전역 ID** | **로드아웃 명칭** | **임무 성격** | **하위 배리에이션** |
| :--- | :--- | :--- | :--- |
| **LO-MOV** | Mobile Loadout (이동) | 야전 · 기동 | 단일 (100%) |
| **LO-OBS** | Observation Loadout (관측) | 야전 · 정찰 | VR / LS / TR / UR |
| **LO-SIG** | Signal Loadout (통신) | 야전 · 통신 | SC + RD |
| **LO-CMD** | Command Loadout (지휘) | 결심 · 지휘 | DA / BO / DI × STATION / FIELD |
| **LO-CARE** | Care Loadout (돌봄·동반) | 동반 · 돌봄 | 단일 (앰비언트) |
| **LO-INS** | Inspection Loadout (검증) | 검증 · 인정 (oversee) | INS-A / INS-C / INS-O |
| **LO-TRN** | Training Loadout (단련·준비) | 단련 · 준비 (readiness) | TRN-RUN / TRN-STN / TRN-GMS / TRN-SHT |
| **LO-HMNT** | Hunt Maintenance Loadout (사냥 정비) | 정비 · 존속 | ARC / WFL / CMP / SCT / DOG / PAK / BOT |
| **LO-MTRB** | Moto Trailblaze Loadout (모토 개척) | 개척 · 자립 | MTRB-MNT / MTRB-CMP / MTRB-NAV / MTRB-PAK |
| **LO-SR** | Special Reconnaissance (특수정찰) | 침투 · 관측 · 송신 | SR-MOV / SR-OBS / SR-SIG |
| **LO-CR** | Clandestine Reconnaissance (은밀정찰) | 정찰 · 수집 (deniable) | CR-APP / CR-PRP / CR-MOV / CR-OBS *(BLACK 전속)* |


# SECTION 03 — 제품 설계 가치 체계

> CQR의 모든 제품을 관통하는 거시 설계 축과 8대 핵심 가치를 정의하는 브랜드 공통 엔지니어링 프레임워크

## 3.1 2대 상위 거시 축 — The Two Value Domains

의류는 신체와 환경 사이를 매개하는 **휴대 가능한 환경(Portable Environment)**이다. (Watkins & Dunne, *Functional Clothing Design*)

CQR은 의류의 매개 역할을 **Reliability(신뢰성)**와 **Agility(민첩성)**라는 2대 거시 축으로 분화한다.

* **Reliability:** 극한 환경과 반복적인 하중 속에서도 신체와 자산을 보호하고 제품 성능을 결코 상실하지 않는 방벽(Barrier) 역할.
* **Agility:** 신체의 가동역을 해방하고 부하를 줄여 어떠한 국면에서도 착용자의 반응 속도를 끌어올리는 증폭기(Enabler) 역할.

모든 CQR 제품은 두 가치의 기본 표준을 만족하며, 라인의 목적과 임무에 따라 핵심 강조점이 조율된다.

| **거시 축** | **정의** | **의류의 역할** |
| :--- | :--- | :--- |
| **Reliability (신뢰성)** | 거친 환경과 물리적 부하 속에서도 장비와 신체를 결코 실패 없이 지켜낸다는 확신 | **방벽 (Barrier)** — 위협 차단, 하중 분산, 장비 유지 |
| **Agility (민첩성)** | 신체 움직임과 반응 속도가 옷에 의해 제약받지 않는다는 확신 | **증폭기 (Enabler)** — 가동역 해방, 체력 소모 경감, 반응 신속화 |


## 3.2 8대 핵심 가치 축 — Core Value Axes

8대 핵심 가치 축은 CQR 제품을 엔지니어링하고 평가하는 공통 기준점이다.

| **방향성** | **핵심 가치** | **CQR에서의 정의** | **대표 원단 / 엔지니어링** |
| :--- | :--- | :--- | :--- |
| **Reliability** | **Durability <br>(내구성)** | 거친 물리적 마찰과 환경을 끝까지 견뎌내는 소재와 구조의 강인함 | DURATEX |
| | **Reinforcement <br>(보강)** | 마찰 및 충격 집중 부위를 구조적으로 덧대어 파손을 원천 차단하는 설계 | 원단 덧댐 · 바텍 |
| | **Protection <br>(방호)** | 기후, UV, 수분, 파편 등 외부 위협으로부터 신체를 차단하는 방벽 능력 | UPF · Water-Resistant |

| | **Ventilation <br> (통기·배출)** | 열과 습기를 능동 배출하여 장시간 임무 수행력을 지속시키는 설계 | 타공 구조 · 메시 주머니감 |

## 4.1 LIBERATOR — FREEDOM · THE TRAINED PROFESSIONAL

LIBERATOR는 **자유(FREEDOM)를 지키고 실현하는 훈련된 전문가**를 상징한다.

군사·전술 분야에서 풍부한 현장 경험과 실력을 쌓은 인물을 원형 캐릭터로 삼으며, 현역 오퍼레이터부터 전역 후 교육·자문으로 영역을 확장한 베테랑까지 아우른다.

## 4.2 EXPEDITION — FRONTIER · PURPOSE-DRIVEN OPERATOR

EXPEDITION은 개척(FRONTIER)을 위해 적대적 자연으로 들어가는 원정대원이다.
적대적 지형은 정복 대상이 아닌 읽고 통과해야 할 필드이자 임무 공간이 된다.

### 4.2.1 EXPEDITION ALPINIST
* **Aspiration Gap:** 주말 등산객 → 지형을 오퍼레이터의 눈으로 읽고 고지를 확보하는 원정대원
* **특징:** 정상을 보상이 아닌 목표물로 인식하며 능선과 진지를 점령하는 수직적 프론티어

### 4.2.2 EXPEDITION RIDER
* **Aspiration Gap:** 취미 라이더 → 미지의 영역으로 밀고 들어가는 프론티어 개척자
* **특징:** 웨스턴 전통과 개척 정신에 기반하여 수평의 열린 도로를 끝까지 개척하는 트레일블레이저

### 4.2.3 EXPEDITION HUNTER
* **Aspiration Gap:** 아웃도어 애호가 → 발견되기 전에 사라지는 필드의 숙련된 사냥꾼
* **특징:** 정숙함과 인내로 야생의 사이클을 읽고 지형에 완전히 용해되는 정지의 전문가

---

## 4.3 COVERT — JUSTICE · THE SILENT OPERATOR

COVERT는 도심에서 정의(JUSTICE)가 작동하도록 잠복·감시·관찰을 수행하는 요원이다.
100% 시민의 외형으로 완전히 녹아들되, 시선과 자세 속에서 은밀한 임무가 실행된다.

* **주요 직업군:** CSI, FBI 수사관, 정보 분석관 (국내 배지 효력 유지 직업군 중심)
* **COVERT vs BLACK (도심 경계):** COVERT는 100% 일반 시민 위장(수동적 관찰)을, BLACK은 은근한 택티컬 미감을 드러내는 능적 작전 주체(Overwatch)를 담당한다.

---

## 4.4 SAPPER — PROSPERITY · FOR FUTURE MAKERS

SAPPER는 번영(PROSPERITY)을 건설하는 최첨단 현장의 공병이다.
단순 현장 노무자가 아닌 격납고, 로봇 공장, 클린룸을 총괄 감독하는 **Lead Engineer / Chief Inspector (Oversee Tier)**의 정체성을 부여한다.

9-1. 존재 이유 — 레지스트리가 채우지 못한 축

기존 7종은 임무 수행 중(기동·정찰·통신·지휘), 임무 곁(동반·돌봄), 완성의 검증(oversee), 임무 사이의 준비(readiness)를 덮었지만, **자기 장비와 거점을 계절 너머로 존속시키는 임무 축**은 비어 있었다. LO-HMNT가 이 공백을 채운다.

- **PAA 정합 — "쉬는 캐릭터"는 존재하지 않는다**: CQR 캐릭터는 오두막에서 그냥 쉬지 않는다. 그러나 겨울·오프시즌·보온 레이어 제품군은 필연적으로 "캠프에 머무는 남자"를 그려야 한다. LO-HMNT는 이 모순을 해소한다 — **머무는 것 자체를 임무로 전환한다.** 장작을 패는 손, 트럭에서 짐을 내리는 손, 데코이에 붓을 대는 손은 전부 캠프와 사이클을 존속시키는 노동이다.

- **A GAP — 사이클을 아는 남자**: 기존 HUNTER 갭(주말 사냥꾼 → 진짜 사냥꾼)의 **시간 축 연장**이다. 새 갭을 발명하지 않고 같은 갭을 "시즌 밖"으로 확장했다(설명 비용 0). 주말 사냥꾼은 시즌이 끝나면 장비를 차고에 던져두지만, 진짜 사냥꾼은 시즌이 끝나도 캠프를 건사하고 다음 시즌을 준비한다.

9-3. 핵심 문법 — "정비되는 중" 시제

시그니처는 특정 장비가 아니라 **장비의 상태**다. 모든 자산은 진행형으로 존재한다 — mid-repair(수선 중인 데코이) · taken apart(분해된 덕콜) · laid out for inspection(펼친 트리스탠드 스트랩) · open case(열린 보우 케이스) · airing(볕에 말리는 크레이트) · door ajar(방금 나온 문). 이 시제 어휘가 두 가지를 동시에 해낸다: ① 임무가 지금 진행 중임을 증명 ② 정적 인물+소품 조합이 "소품 앞에서 사진 찍는 남자"로 미끄러지는 것을 방어.

**층위 분리 불변** — 몸은 최소, 정비 도구조차 손에 쥐지 않는다. 모든 기어 밀도는 환경(C열)에 있고, 도구는 벤치·테일게이트·포치에 스테이징된다. "방금 손을 뗀 남자"가 기본 프레임이다.

9-5. 무기 정책 (오너 확정)

레지스트리에서 **총기 정책이 카테고리 DNA인 두 번째 로드아웃**이다(첫 번째 = TRN-SHT의 해금 — 방향은 정반대).

- **총기 = 전면 0**: 총기 본체뿐 아니라 클리닝 로드·솔벤트·건 오일 등 총기 정비 키트 일체 금지 — 총기를 소환하는 소품은 총기와 같다. 총기 정비의 서사 자리는 HMNT-ARC가 대체한다.

- **보우 = 화기보다 1단계 열린 등급**: 케이스 밖 노출 허용 · 벤치 수평 거치 · 월랙 수직 거치 · field points 명기 화살 · 타깃 블록의 연습 흔적까지 허용. **인물 파지 일체 · 드로우(시위 당김) 일체 · 브로드헤드 노출 · 무명 화살 · 사격/조준 행위 묘사는 금지.** "총은 없지만 사냥 무기를 정비한다"는 서사가 성립하면서 무기의 전면화는 차단된다.

9-6. 시각 언어

- **계절 = 정체성 마커**: hard frost 또는 thin first snow — 깊은 눈 0. 플라넬 3형제의 snow-free 가을 규칙을 의도적으로 깨는 첫 카테고리다. 보온 레이어 제품(플리스)과 추운 기후가 논리로 붙는다.

- **광 = cold + bright**: crisp·cool·pale로 춥게, clear·bright로 밝게. 야간·dusk·blue hour·gloomy 0 불변 — 추위는 어둠이 아니라 맑음으로 그린다.

- **공간 = 구조물 앵커**: 전 씬 필드 미진입. 캐빈·포치·기어 셰드·우드셰드·보트하우스·테일게이트가 작업대다. 배경 공통 = 팬 장작 + 굴뚝 연기. Alone in the Wild(필드 진입)와의 결정적 변별 마커.

- **관계 소품 — 개 off-duty 레지스터**: 기존 두 레지스터(작업·다정) 사이의 세 번째. 개는 남자를 보지 않고 **남자와 같은 방향을 본다** — 마주보는 관계도, 지시-수행 관계도 아닌 **나란히 있는 동료** 구도. 오프시즌이므로 개도 off-duty라는 계절 논리가 뒷받침한다.

*금지 자산(통합) — 총기 일체 + 총기 정비 키트 · 브로드헤드 노출 · 보우 파지/드로우 · tactical/operator 기어 · 글램핑 스타일링 · 야간·dusk·gloomy 광 어휘 · 제복·휘장 · 깊은 눈 · 고기/정육 · 디지털 관측 단말(로그북은 종이).*

LO-MTRB — moto trailblaze loadout (모토 개척)

**축****: ****개척****·****자립****(pioneer·sustain) · 4 sub-variants (MTRB-MNT / MTRB-CMP / MTRB-NAV / MTRB-PAK) · ****적용****: EXPEDITION RIDER(****모토****) ****계열**

레지스트리의 **9번째 등록 로드아웃**이자 **최초의 모터사이클 자산 로드아웃**. 미개척 지형을 어드벤처 바이크로 먼저 통과·검증해 후발대의 통로를 개척하는 **트레일블레이저** 자아상을 운반한다 — 혼자 즐기는 라이딩에서 뒤에 올 이들을 위한 첫 통과(route-proving pathfinder)로의 이동. 기존 RIDER 갭(취미 라이더 → 프론티어 개척자)을 "먼저 길을 여는 자"로 구체화한다.

10-1. 공통 정체성

- **캠프 앵커 의무**: 제품(후디)이 보호장비가 아니므로 **주행 맥락 씬을 금지한다.** 전 씬이 캠프사이트를 앵커로 성립하며, 바이크는 항상 사이드스탠드 거치("라이딩은 끝났다" 신호). Function-to-Style 정합의 핵심 규율이다.

- **탑재 테스트**: 씬에 등장하는 모든 캠프 물품은 그 바이크에 실려 도착했다고 믿어져야 한다. 글램핑·차박 스케일은 자동 배제된다.

- **명명 노트**: MTRB = moto-trailblaze 축약. 4글자 선례(LO-CARE·LO-HMNT)를 따른다. M은 라인 머리글자가 아니라 적용 범위의 선언이다 — 자산 풀 자체가 모터사이클 전용이라 "모토 개척"이 하나의 임무 단위다.

LO-SR — special reconnaissance loadout (특수정찰)

**축****: ****침투****·****관측****·****송신****(infiltrate·observe·report) · 3 sub-variants (SR-MOV / SR-OBS / SR-SIG) · ****적용****: LIBERATOR MODERN ****야전**

레지스트리의 **10번째 등록 로드아웃**. LIBERATOR MODERN의 야전 임무 로드아웃으로, 현역 특수부대 오퍼레이터의 **비교전 임무 국면**을 담당한다. 침투 이동(MOV) → 관측 거점(OBS) → 통신 수립(SIG) 세 축이 하나의 임무 서사를 이룬다.

11-1. 철학 — 왜 특수정찰인가

**총기 회피가 타협이 아니라 임무의 본질인 유일한 군 임무.** "쏘지 않고, 발견되지 않고, 돌아와야 성공. 이 남자의 임무에서 총성은 곧 실패다." CQR의 총기 미표현 원칙과 특수부대 리얼리즘이 충돌 없이 만나는 지점이 SR이다 — 화면에 총이 없는 것이 검열이 아니라 임무의 정확한 묘사가 된다.

- **recce 리얼리즘**: "이 남자의 방어는 장갑이 아니라 발견되지 않는 것이다." 장거리 정찰 교리에서 무장갑·경량 키트는 표준이다 — 하중 대신 기동, 장갑 대신 은밀. 이 교리 덕에 플레이트 캐리어 없이 제품(후디)이 최외피로 온전히 노출된다. **리얼리즘과 제품 노출이 같은 방향을 가리키는 구조.**

- **직업 증명의 원칙**: "캐릭터의 직업은 행위가 아니라 자산 풀이 증명한다." 격발·교전 장면 없이 위장망·NVG·맨팩 무전·관측 로그가 있는 화면은 특수부대에만 존재한다. 검증 질문: *이 화면의 물건들을 보고 다른 직업을 상상할 수 있는가?* — NO여야 합격.

5. **위장망 = 환경 자산 허용, 인물 위장 페인트 0** (HUNTER 실루엣 거리 관리).

*계보 문장: "이 후디의 문법은 SOCOM 한랭 전투복의 문법이다 — L4의 풀오버 구조에 L5의 벨크로·팔지퍼 사양을 결합했다." 색상 3색(블랙·네이비·차콜) 전부 고증 정합 — 차콜·블랙은 군용 라인 표준 팔레트, 네이비는 해안·해상 결(권역 B 우선). 금지선은 원색·고명도·형광.*

11-6. 장비 어휘 — 아카이브 깊이 원칙

장비는 **시대 중립 클래식 실루엣**으로 표기한다: night-vision goggles · high-cut ballistic helmet · field manpack radio · rugged end-user device · compact binoculars · spotting scope · compact folding reconnaissance quadcopter · satellite puck.

*아카이브 깊이 원칙 — 렌더 어휘의 구체성은 실물의 신형 여부가 아니라 사진 아카이브 깊이가 결정한다. 사진 이력이 두터운 실물은 고유명, 실물은 최신이나 사진 희소하면 클래식 실루엣 generic으로 표기한다. "최신 장비" 지정은 렌더에게 본 적 없는 것을 그리라는 지시가 되어 인체 비례 붕괴로 귀결된다. 부수 효과: 시대 중립 장비는 씬의 수명을 늘린다.*

11-7. 확장 예약

- **카고팬츠·컴뱃셔츠** — 같은 LO-SR을 그대로 사용(후디가 라인 전체의 로드아웃 인프라를 선행 구축).
- **SR-INF(침투 개시·인서션)** — 대형 자산(수송기·헬기) 부활의 유일한 문. 시제 충돌 검토 후 판정.

LO-CR — clandestine reconnaissance loadout (은밀 정찰)

**축****: ****정찰****·****수집****(recon·collect) — deniable · 4 sub-variants (CR-APP / CR-PRP / CR-MOV / CR-OBS) · ****적용****: LIBERATOR BLACK ****야전**** (****전속****)**

레지스트리의 **11번째 등록 로드아웃**. LIBERATOR BLACK의 야전 임무 로드아웃으로, 숲속 깊은 곳의 적 비밀기지를 침투 전 정찰하는 **배지 소거(deniable) 요원**의 임무를 담당한다. 차량으로 기지 근처 숲까지 이동(APP) → 지도·목표물 사진으로 최종 준비(PRP) → 도보 은밀 정찰(MOV) → 원거리 관측(OBS). Urban Overwatch가 도시의 BLACK이라면 LO-CR은 **숲의 BLACK**이다.

12-1. 라인 전속 — 라인 중립 원칙의 명시적 예외

LO-CR은 자산 하나하나가 배지 소거 정체성을 인코딩한다 — 글록(MODERN "총기 0" 위반) · 민수 차량(군은 민수 차량으로 침투 정찰 안 함) · 목표물 사진(수사 파일 톤, 군 관측 로그와 다른 계보) · 위장망·헬멧·맨팩 전면 금지(MODERN 임무 앵커의 정확한 부정). 따라서 **LIBERATOR BLACK 전속이며 타 라인 적용을 금한다.** LO-CMD가 여러 라인에 겸용될 수 있었던 것은 자산이 중립적이기 때문이고, LO-CR은 자산이 당파적이라 겸용이 불가하다.

| 자산 풀 | 헬멧+NVG 팩 거치·위장망·맨팩 무전·관측 로그 | 민수 차량·종이 지도·목표물 사진·컴팩트 쌍안경 |
| 무기 | 총기 0 (총성은 곧 실패) | 글록만 — C열 0 + 포즈 레이어 홀스터 |
| 표적 | 없음 (지형 정찰) | 적 비밀기지 — 단 **완전 비노출** |

12-4. 카테고리 불변항 (전 씬)

1. **C열 총기 0** — 글록은 포즈 레이어 홀스터 거치(파지 아님). 파지 = 교전 국면 냄새 → 은닉성 파괴. PRP 소품 배치 포함 C열 등장 전면 금지.
2. **군 자산 0** — 헬멧·NVG·위장망·맨팩 무전·안테나·관측 로그·EUD·삼각대·스코프. 한 점이라도 등장하면 복무 상태 경계표 붕괴.
3. **기지 완전 비노출** — 목표물 사진 속에만 존재. 원경 실루엣 포함 렌더 0. (비노출은 "구조물 없음" 류 부정 어휘가 아니라 언급하지 않음으로 집행 — 부정 명사가 대상을 소환하는 렌더 리스크 차단.)
4. **차량 = APP·PRP 한정** — MOV·OBS 화면에 차량 0("차를 뒤로 하고 걸어 들어갔다"를 부재로 증명).
5. **트레일 어휘 금지(MOV-T)** + undisturbed frost ahead 시그니처 의무.
6. PC·체스트리그 0(제품 노출) · 로고·배지·패치 0 · 번호판 어휘 0 · 야간·석양 0 · deep snow 계열 금지(snow는 그늘·움푹한 곳 patchy 한정).

12-5. 계절 상수 — "초겨울 문턱"

눈 가득 금지, 막 겨울이 시작되려는 풍경. 지면은 thin frost + 그늘진 곳에만 patchy first snow(개활면은 맨땅+서리), 식생은 마른 갈색 잎·다크 에버그린·서리 낀 이끼, 대기는 차고 고요한 공기·낮은 회색 overcast·나무 사이 옅은 아침 안개. 강설 진행형·눈보라·단풍 절정(가을 회귀)은 금지. **눈 면적을 통제해 블랙 제품·차량 대비를 유지**하는 것이 계절 규칙의 실질 목적이다. SR 벨크로 후디(쌀쌀한 가을)·HMNT 플리스(frost/first snow) 계보의 연장 — 계절이 곧 플리스 착용 알리바이.

12-6. 배경 운용

- **권역 3종** (해외 한정 — 실명 기지 0): 카르파티아 / 발트 타이가 / 디나르 카르스트 침엽수림. Urban Overwatch의 해외 한정을 숲으로 확장.
- **광 3창**: 이른 아침 · overcast · 늦은 오후. 야간 0 (SR 대비 overcast 상향 — 회색 하늘이 계절 신호이자 은밀 무드).
- **차량**: 블랙 무광 대형 SUV — 동유럽·발칸에서 기관·경호 차량의 사실상 표준("요원 코드" 판독). 웨더링 lock("깊은 오지에서 오프로드를 오래 달려온 차" — 쌓인 먼지·와이퍼 호·2겹 진흙 크러스트, no gloss). 세부 기종명은 별도 프로덕션 가이드에서 관리한다.

*설계 교훈 (일반화) — ① "씬 자산이 자세를 결정한다": 이동 국면은 staged 자산이 아니라 통과 지형 문법으로 설계한다(내려놓은 팩이 있으면 포즈가 정지로 강제됨). ② 차량은 서사 장치지 제품 무대가 아니다 — 차량 국면은 최소로, 노출은 인물 국면으로. ③ 웨더링은 "튄 흔적"이 아니라 "시간의 층위"로 쓴다.*
