# PM Skills attribution

The CQR market-research workflow adapts output-structure ideas from
[`phuryn/pm-skills`](https://github.com/phuryn/pm-skills) (MIT License):

- `pm-market-research`: user personas, user segmentation, market segments,
  customer journey map
- `pm-product-strategy`: pricing strategy
- `pm-go-to-market`: competitive battlecard
- `pm-execution`: create PRD, prioritization frameworks, pre-mortem, job stories

Only framework and output-shape ideas are adapted. CQR-specific prompts, schemas,
evidence gates, Korean output rules, apparel fields, and runtime integration are
implemented in this repository.

Upstream repository checked: 2026-07-30.
