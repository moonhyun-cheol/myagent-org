# 상품 라인업 데이터 계약

ORGANIZATION_BRAND_CONTEXT

원본 주소는 설정 키 `product_lineup_url`(org `module.json` 주입)에서 읽는다. 이 문서에는 원본 URL이나 제품 스냅샷을 보관하지 않는다.

## 필드 해석

| 필드 | 활용 | 주의 |
|---|---|---|
| 라인 | 라인별 포지셔닝·분류 | 원문 명칭 유지 |
| 발주서명 | 내부 상품/생산 분류 참고 | 대외 상품명·소재명과 혼동 금지 |
| 모델번호 | 제품 연결·추적 | 스타일명이 같아도 모델번호별 구분 |
| 스타일명 | 제품 표기 | 빈 셀의 이름을 창작하지 않음 |
| 배경 | 비주얼·사용 장면 콘셉트 | 실제 사용 실적·기관 협업 아님 |
| 로드아웃 | 관련 콘셉트 묶음 | 코드 의미 미확인 시 원문 유지 |
| 원단명 | 소재 메시지 근거 | 성능 수치·인증을 추론하지 않음 |
| 혼용률 | 사양 근거 | 빈 셀은 미기재, 기호 해석은 확인 필요 |
| 슬로건 | 기존 메시지 참고 | 후보·수정 메모·변경 이력이 혼재 가능 |
| 시즌 | 시즌별 후보 필터 | 현재 출시 시즌/판매 가능 여부와 다름 |
| 카테고리 | 분류·상품 묶음 | 복합 분류 원문 보존 |
| 상태 | 원본 진행 상태 | 재고·출시·공개 승인과 구별 |

## 분석 규칙

- 전체 응답을 확보하기 전 `전체 라인업`, 누락 없는 총계, 모든 후보라고 주장하지 않는다.
- Markdown 이스케이프 파이프(`\|`) 등은 셀 경계와 구별한다. 행 길이가 헤더와 맞지 않으면 해당 행의 해석을 보류한다.
- 이름/코드 비교용 공백 정리는 가능하나 표시와 인용에는 원문을 유지한다.
- 정량 요약은 조회된 표의 상품 행 수를 기준으로 하고 필터, 제외 상태, 중복 처리 방식을 함께 기재한다. 시장 규모·수요·매출은 도출하지 않는다.
- 상태별 후보군을 분리한다. 단종을 제외했어도 나머지가 판매 가능한 제품이라는 뜻은 아니다.
- 검색 결과 없음은 `이번 조회본과 조건에서 일치 없음`이지, 제품이 존재하지 않는다는 확정이 아니다.
- 생성일 누락은 `원본 생성일 미기재`, 조회 성공 시각은 실제 관측값으로 기록한다.
