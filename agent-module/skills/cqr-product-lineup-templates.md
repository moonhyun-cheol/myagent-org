# 분야별 활용 템플릿

ORGANIZATION_BRAND_CONTEXT

각 분야 모두 `skills/cqr-product-lineup.md`의 최신 조회, 모델번호별 근거, 사실/제안 구분 규칙을 먼저 적용한다. 빈칸은 조회 결과와 사용자 조건으로 채우며, 계획 수치는 가정 또는 목표라고 표시한다.

## 1. 마케팅안

- 입력: 목표, 타깃, 시즌, 채널, 예산·기간(미정이면 가정).
- 결과: 캠페인 방향 → 모델번호별 후보·선정 근거 → 메시지/제안 카피 → 채널별 소재 → 일정·KPI 목표 → 확인 사항.
- 제한: 원단명만으로 성능 우위를 확정하지 않는다. 기존 슬로건은 확정 여부를 확인하고, 준비중/DRAFT 제품은 출시 확정 전 캠페인 후보로만 다룬다.

## 2. 상품·캠페인 기획안

- 입력: 문제/기회, 대상 라인·카테고리·시즌, 일정·제약.
- 결과: 현황 → 기존 제품 매핑 → 콘셉트와 차별화 가설 → 후보 조합 → 실행 단계 → 검증 과제.
- 제한: 신규 상품 아이디어는 `신규 제안·원본에 없음`으로 표시한다. 실제 모델번호를 부여하지 않는다. 라인업의 빈 영역만으로 시장 수요를 확정하지 않는다.

## 3. 콘텐츠·상세페이지·카피

- 입력: 대상 모델번호, 채널, 톤, 분량.
- 결과: 확인된 제품 정보 → 스토리 구조 → 제안 제목/카피/비주얼 방향 → 근거 연결 → 발행 전 점검.
- 제한: 미기재 사양은 쓰지 않는다. 배경 콘셉트를 실제 기관 사용 사실로 표현하지 않는다. 원본 슬로건과 제안 카피를 구분한다.

## 4. 영업·상품 제안

- 입력: 고객 유형, 사용 환경, 시즌, 요구 조건.
- 결과: 모델번호별 후보 비교 → 고객 요구와 연결한 제안 이유 → 미충족/미확인 조건 → 가격·재고·납기 확인 목록.
- 제한: 목록만으로 공급 가능, 즉시 납품, 인증 충족, 고객사 레퍼런스를 보장하지 않는다.

## 5. 라인업 분석·내부 보고

- 입력: 분석 범위, 비교 기준, 상태 포함 정책.
- 결과: 출처·필터·행 수 기준 → 라인/시즌/카테고리/상태별 현황 → 중복·누락·카피 충돌 → 개선 제안 → 담당자 확인 목록.
- 제한: 진행 상태 집계와 판매 중 제품 집계를 혼동하지 않는다. 과거 비교본이 없으면 증감·신규 추가·삭제를 추정하지 않는다.
